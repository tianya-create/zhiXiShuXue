# 智析数学 V1.0 学校试用说明

本说明面向准备在校内小范围试用的数学教研组与信息管理员。

当前版本已经打通"教材进度 → 作业/练习 → 自动判分 → 教师复核 → 错题本与掌握度 → 复习计划"的完整链路，但这只说明软件流程可以跑通，**不代表题库已经过教师审核，也不代表学习效果已经得到验证**。

## 一、开始使用

1. **建账号**：管理员在「用户管理」创建教师账号；教师登录后在「班级管理」创建班级，在「学生管理」创建学生账号（学号即登录名）。
2. **设教材进度**：教师在「班级管理 → 教材进度」填写教材版本，勾选这个班**已经学过**的知识点。
   - 未配置时系统不限制练习范围；配置后，个性化推荐与专项补练只在已学范围内出题。
   - 目录中的年级只是建议，以教师核对的实际教学进度为准。
3. **备题与审核**：在「题目管理」录入题干、选项、答案、解析、知识点和难度。
   - 保存时系统会做质量校验：选项必须唯一、答案必须对应选项、分值在 1–100、评分步骤合计等于总分、图片必须走上传入口、审核通过前必须有解析。
   - 解答题可设置步骤分值，复核时按步骤给分。
4. **布置作业**：在「作业发布」选择班级与试卷。学生作答时草稿自动保存（先存本机，再同步服务端），断网、刷新、换设备都能接着答；交卷有唯一提交编号，重复点击不会重复统计。
5. **复核**：教师在「复核与纠错」处理待复核答卷。
   - 解答题、含根号/三角函数的答案、图片作答一律进入人工复核，不由文字相似度直接给分。
   - 保存复核结果后，系统同步更新成绩、错题本与掌握度；重复复核不会增加作答次数。
6. **学生练习**：学生可在知识图谱、薄弱点、错题本进入针对性练习。工作台底部显示「复习计划」，按 1、3、7、15 天的间隔安排复习；同一天连答两次不会直接把错题标成已掌握。

## 二、判分规则（可解释、可复核）

| 题型 | 判分方式 | 不确定时 |
| --- | --- | --- |
| 选择题 | 选项字母/内容归一后比较 | 无 |
| 判断题 | 「对/错、√/×、true/false」归一到标准表述 | 无 |
| 填空题 | 代数等价判定：`1/2 = 0.5`、`2(x+1) = 2x+2`、`x=6` 与 `6` 等价；同时支持教师录入的可接受答案 | 含根式、π、三角函数、分式含变量等无法解析的写法，转人工复核 |
| 解答题 | 只给出相似度建议，**始终转人工复核** | 始终 |

等价判定使用有界的有理式解析器（BigInt 分数运算），不做随机取样、不执行 `eval`，只承认语法范围内的恒等变形。

## 三、掌握度与学情

- 掌握度取最近 10 次有效作答的正确率，连对 3 题 +10、连错 2 题 −10。
- 有效样本不足（少于 5 次作答，或不同题目少于 3 道）时显示「样本不足」，掌握度封顶 79，不认定"已掌握"。
- 未作答的知识点显示「尚未测评」。
- 教师端与学生端使用同一套掌握度计算；作业成绩按满分折算为百分比；**等待复核的提交不计入最终成绩与掌握度**。
- 掌握度与学情统计统一落在 30 个教材目录节点上，历史题目里的旧编号（`kp-001` 等）会按等价关系归一到目录节点。

## 四、数据、权限与安全

- 所有业务数据（账号、班级、作业、答卷、草稿、错题、掌握度快照）持久化在 SQLite，重启不丢失；开启 WAL 与 `busy_timeout`，避免并发写锁。
- **行级权限**：学生只能读写自己的记录；教师只能访问自己班级的学生、作业、答卷与统计；管理员可跨班级。
- 所有接口响应统一脱敏，不会返回密码哈希、密钥、令牌版本号。
- 登录失败限流：同一 IP + 账号 15 分钟内失败 10 次即暂时拒绝；被禁用账号无法登录。
- 改密、被禁用、主动退出都会使旧令牌立即失效。
- 学生请求练习题时不返回标准答案；交卷后才返回正确答案与解析（待复核的题目返回"等待复核"）。

## 五、部署与运维

1. 复制 `backend/.env.example` 为 `backend/.env`，至少修改：
   - `JWT_SECRET`：随机且不少于 32 字符
   - `INIT_ADMIN_PASSWORD`：首次初始化的管理员密码（不少于 12 位）
   - `WEB_ORIGIN`：实际访问域名，用于跨域白名单
2. `docker compose up -d --build`，前端 80 端口，后端 5001 端口。
3. 备份：停止后端后拷贝 `backend/database/*.sqlite`（含 `-wal`/`-shm`）与 `backend/uploads/`；或在服务运行中执行 `sqlite3 app.sqlite ".backup backup.sqlite"` 做一致性备份。
4. 升级：拉取新版本后重新构建镜像。数据库表结构向后兼容，启动时会自动补齐新增的教材节点（只补齐，不覆盖后台改过的名称）。

## 六、教学内容边界

- 当前目录包含 30 个初中数学常见知识主题（数与式 8、方程与不等式 5、函数 4、几何 7、统计概率 6），提供年级建议与前置关系，**不是任何具体教材的完整章节目录**。使用前请按学校教材核对，并补充细分知识点与足量审核题目。
- 预置练习题中有相当一部分是系统生成的模板题，仅用于打通流程；正式试用前必须由教师替换或重新审核。
- 图片上传仅用于人工复核，当前不声称能通过 OCR 自动批改手写解答。
- 题库支持 `$...$` / `$$...$$` 的 LaTeX 公式渲染；直接输入 `x²`、`√2`、`π` 也能正常显示。

## 七、小范围试用验收

建议先选**一个班、一个已学章节**，由任课数学教师完成题目审核，再运行两周，记录以下指标：

| 指标 | 采集方式 |
| --- | --- |
| 题目纠错率 | 「复核与纠错 → 题目纠错」条数 ÷ 作答题次 |
| 自动判分与教师判分分歧 | 复核时被改分的题目数 ÷ 待复核题数 |
| 草稿恢复成功率 | 抽查中断后重新进入的恢复情况 |
| 练习完成率 | 已提交练习 ÷ 已打开练习 |
| 复习后独立作答正确率 | 复习计划到期题目的二次作答结果 |
| 教师单份答卷处理时间 | 复核耗时抽样 |

用这些证据决定是否扩大范围；**不要用"功能上线""测试通过"或页面上的掌握度替代学习效果验证**。

## 八、软件验证

仓库自带后端测试（Jest）：

```bash
cd backend
npm test
```

覆盖范围包括：身份伪造与跨班越权、响应脱敏、数学等价判分、题库质量校验、作业/练习重复提交幂等、草稿读写、教师复核后掌握度更新、知识点目录完整性。

也可以直接运行端到端脚本（需要后端已启动）：

```bash
python tests/e2e_learning_loop.py
```
